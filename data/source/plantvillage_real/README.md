Citation: Mohanty, S. P., Hughes, D. P., & Salathé, M. (2016). Using deep learning for image-based plant disease detection. Frontiers in Plant Science, 7, 1419. https://doi.org/10.3389/fpls.2016.01419

The source test split is exported as `val`; the official source split is preserved. The fungal class is specifically tomato Septoria leaf spot, not a general fungal-disease class. See `manifest.csv` for original image paths and source labels.
